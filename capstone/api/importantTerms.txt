signin,jsx - is ung nakikita ng tao tas kung san nag iinput

auth.js - messenger, nag sesend ng input mo sa login

vite config.js - pang open ng server na file







login flow:

sign in page(signin.jsx) - input mo yung credentials

auth.js - kukunin niya ung input mo ibibigay niya sa login

vite config.js - transporter ng message sa port ng php

log in.php - ichecheck niya yung input mo kung meron ka sa table 

db.php - gagamitin ng log in.php ung file na to para macheck niya ung table

auth.jsx - signin page - app.jsx > irereceive nung auth ung message tas ibabalik sa program tas makakapasok kana
